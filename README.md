# AmpliconTyperGUI
A desktop application for running [AmplicanTyper](https://github.com/AntonS-bio/AmpliconTyper) classification, implemented with
[Electron](https://www.electronjs.org/).

### :wrench: This is a work in progress. :wrench:

This repo contains the following components in its directories:
* `amplicontyper-installer` - a PyInstaller spec for building the classify functionality of AmpliconTyper as a portable executable, to be used by the Electron app.
* `amplicontyper-electron` - the Electron app GUI.

`test_data` contains test data copied from the AmpliconTyper repostory.

See the README files in these directories for more details.
